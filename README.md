# A Gamified LEGO Framework for Teaching Signals and Systems

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23890512.svg)](https://doi.org/10.5281/zenodo.23890512)

This repository contains the dataset and computational materials associated with the study **“A gamified LEGO framework for teaching signals and systems.”**

The project investigates a hands-on, gamified LEGO-based approach to teaching core concepts in Signals and Systems. The repository is organized to make the data, analysis workflow, and generated figures accessible and reproducible.

## Archived release

The version **1.0.0** is archived in Zenodo:

- **DOI:** [10.5281/zenodo.23890512](https://doi.org/10.5281/zenodo.23890512)
- **GitHub release:** [v1.0.0 – Initial research release](https://github.com/aquinteroz/gamified-lego-signals-systems/releases/tag/v1.0.0)

### Main contents

- **`data/raw/data_share.xlsx`** — research dataset used in the analysis.
- **`data/processed/`** — directory reserved for derived or processed datasets, if required.
- **`notebooks/gamification_analysis_zenodo.ipynb`** — Jupyter notebook documenting the data processing, statistical analyses, and figure generation.
- **`figures/`** — destination for figures generated by the notebook. The notebook creates this directory automatically if it does not exist.
- **`environment.yml`** — Conda environment specification with the Python version and package dependencies.
- **`CITATION.cff`** — machine-readable citation metadata for the software.
- **`LICENSE`** — license governing reuse of the repository contents.

## Requirements

The analysis environment is specified for **Python 3.13** and managed with Conda.

## Installation

Clone the repository and move into its directory:

```bash
git clone https://github.com/aquinteroz/gamified-lego-signals-systems.git
cd gamified-lego-signals-systems
```

Create and activate the Conda environment:

```bash
conda env create -f environment.yml
conda activate lego_analysis
```

Launch JupyterLab:

```bash
jupyter lab
```

Open `notebooks/gamification_analysis_zenodo.ipynb`.

## Running the analysis

The notebook loads the dataset from `data/raw/data_share.xlsx`. It detects the repository root automatically, whether Jupyter is launched from the repository root or from the `notebooks/` directory.

To execute the complete notebook from the repository root and store the cell outputs in the notebook file, run:

```bash
jupyter nbconvert --to notebook --execute --inplace notebooks/gamification_analysis_zenodo.ipynb
```

The analysis generates figures in the repository-level `figures/` directory. These files can then be reviewed and committed to GitHub alongside the executed notebook.

## Reproducibility

The `environment.yml` file specifies Python 3.13 and the package dependencies used in the analysis. Using this environment helps reduce variation associated with differences in software versions.

The notebook documents the analysis workflow, including data loading, derived variables, statistical procedures, and visualization. A random seed of **2025** is used, and bootstrap-based procedures are configured for **5,000 resamples**.

For a reproducible record, retain the executed notebook and the figures generated from that same execution.
