# A gamified LEGO framework for teaching Signals and Systems

This repository contains the research data and computational materials associated with the study **“A gamified LEGO framework for teaching signals and systems.”**

## Repository structure

```
.
├── data/
│   ├── raw/
│   └── processed/
├── notebooks/
│   └── gamification_analysis_zenodo.ipynb
├── src/
├── materials/
│   ├── activities/
│   ├── assessments/
│   └── teaching_guides/
├── figures/
├── docs/
├── LICENSE
└── README.md
```

## Contents

- `data/raw/`: original dataset files.
- `data/processed/`: processed datasets generated during the analysis.
- `notebooks/`: Jupyter notebooks for data analysis and reproducibility.
- `src/`: reusable source code.
- `materials/`: teaching activities, assessments, and instructional guides.
- `figures/`: figures generated for analysis and publication.
- `docs/`: supplementary documentation.

## Getting started

The dataset and analysis notebook will be added to this repository as supplied. Open the notebook with JupyterLab, Jupyter Notebook, or Google Colab.

## Citation

Citation metadata and the permanent Zenodo DOI will be added when the repository is archived in Zenodo.
